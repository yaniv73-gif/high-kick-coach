# High Kick Coach

PWA לניהול ומעקב אחר תכנית אימונים של 8 שבועות לשיפור גובה ושליטה בהיי-קיק
באיגרוף תאילנדי. עברית מלאה, RTL, מותאם קודם כול לטלפון, ועובד גם ללא
אינטרנט לאחר טעינה ראשונה.

## התקנה והרצה

```bash
npm install
npm run dev
```

פותח שרת פיתוח בכתובת `http://localhost:5173`. לצפייה במובייל, פתחו מהטלפון
כתובת ברשת המקומית (Vite מדפיס אותה בפלט `--host`) או בדקו את גרסת ה-build
דרך `npm run preview`.

## סקריפטים

| פקודה | מה היא עושה |
|---|---|
| `npm run dev` | שרת פיתוח עם HMR |
| `npm run build` | בדיקת טיפוסים (`tsc -b`) ואז build ל-`dist/` |
| `npm run preview` | הרצת ה-build המוגמר מקומית |
| `npm run lint` | בדיקת lint (oxlint) |
| `npm test` | הרצת כל הבדיקות (vitest) פעם אחת |
| `npm run test:watch` | בדיקות במצב watch |

כל הפקודות למעלה עוברות בהצלחה על הפרויקט במצבו הנוכחי.

## התקנה כ-PWA

לאחר `npm run build` + `npm run preview` (או פריסה לאחסון סטטי כלשהו),
פתחו את הכתובת בכרום/אדג' באנדרואיד או בדסקטופ ובחרו "התקן אפליקציה".
לאחר טעינה ראשונה, האפליקציה פועלת גם Offline (Service Worker דרך
`vite-plugin-pwa`, מטמין את כל קבצי האפליקציה).

## ארכיטקטורה

```
src/
  types/           # כל הטיפוסים (Exercise, Workout, WorkoutSession, ...)
  data/            # תוכן קבוע: תרגילים, אימון A/B, יעדי שבועות, ציטוטים
  lib/             # לוגיקה טהורה: התאמת שבוע, סטטוס תכנית, IndexedDB,
                   # ייצוא/ייבוא, כאב, מדיה, פורמט
  hooks/           # useTimer, useWakeLock, useSound, useVibration, ...
  store/           # AppStateContext — הגדרות ופרופיל המשתמש
  components/      # ui/ (רכיבי בסיס), layout/, workout/, exercise-library/,
                   # media/, progress/, assessment/
  pages/           # מסך לכל route
  tests/           # בדיקות vitest
```

**הפרדת שכבות:** נתוני האימונים והתרגילים חיים ב-`src/data`, לוגיקת
ההתאמה השבועית וחישובי הסטטוס חיים ב-`src/lib` (טהורים, נבדקים ביחידה),
ורכיבי ה-UI רק מציגים ומפעילים אותם. אין מסך אחד שמרכז הכול.

### שמירת נתונים

- **IndexedDB** (`src/lib/db.ts`, דרך הספרייה `idb`): אימונים שבוצעו,
  בדיקות שבועיות, קבצי מדיה (תמונות/סרטונים) ומטא-דאטה שלהם.
- **LocalStorage** (`src/lib/storage.ts`): הגדרות (`AppSettings`) ופרופיל
  משתמש קטן (`UserProfile`), לגישה מיידית וסינכרונית באתחול.

### מנוע ההתאמה השבועית

`src/lib/progression.ts` מכיל פונקציה טהורה אחת — `computeWeekAdaptation` —
שמקבלת תרגיל ומספר שבוע (1–8) ומחזירה את החזרות/זמן ההחזקה/הערת התמיכה
והעצימות המתאימים, לפי הכללים שהוגדרו בדרישות (שבועות 1–2 טכניקה,
3–4 נפח, 5–6 פחות תמיכה, 7 דיאלוד, 8 מבחן מסכם). כך אין כפילות נתונים בין
שבועות בקובצי התרגילים עצמם.

### בניית האימון בזמן ריצה

`src/lib/buildSteps.ts` הופך את מבנה האימון (`Workout` → `WorkoutSection` →
רשימת מזהי תרגילים) לרשימת "צעדים" שטוחה למסך האימון הפעיל, כולל פיצול
תרגילים דו-צדדיים לשני צעדים (עם צד חלש קודם, לפי ההגדרה), והזרקת "מבחן
היי-קיק מסכם" בשבוע 8 באימוני A.

## מדיה לתרגילים

בשלב זה כל תרגיל מוצג עם איור סכמטי (SVG) לפי הקטגוריה שלו —
`src/components/exercise-library/ExercisePlaceholder.tsx` — כדי להימנע
משימוש בתמונות/סרטונים מוגני זכויות יוצרים.

להוספת מדיה אמיתית בעתיד:

1. שימו קובץ תחת `public/exercises/images/<exercise-id>.jpg` או
   `public/exercises/videos/<exercise-id>.mp4`.
2. הוסיפו שורה מתאימה ל-`src/data/exerciseMedia.ts` (לא צריך לגעת
   ב-`exercises.ts`).

מדיה שהמשתמש מצלם/מעלה בזמן אמת (סיכומי אימון, בדיקות שבועיות) נשמרת
ישירות ב-IndexedDB, כולל דחיסת תמונות בסיסית בצד הלקוח ו-thumbnail
לסרטונים.

## הרחבות עתידיות (מוכן בקוד, לא מופעל)

הטיפוסים והמבנה נבנו כך שאפשר להוסיף בעתיד בלי שינוי ארכיטקטוני:

- **Supabase**: רשומות (`WorkoutSession`, `WeeklyAssessment`) מוכנות
  לקבל שדות `syncStatus` / `remoteId` (מסומן ב-TODO ב-`src/types/index.ts`).
- **התחברות משתמשים / ריבוי מתאמנים**: `UserProfile` מוכן לקבל `email`
  / `userId` לאחר חיבור Auth.
- **סנכרון בין מכשירים**: שכבת האחסון (`src/lib/db.ts`, `storage.ts`)
  מבודדת מה-UI — ניתן להחליף אותה במקור נתונים מרוחק בלי לגעת במסכים.
- **ניתוח וידאו אוטומטי**: `MediaItem` ו-`MediaTimeline` בנויים כך שאפשר
  להוסיף בעתיד רכיב שמסמן זוויות גוף על גבי הווידאו הקיים.

## בדיקות

`src/tests/` מכיל בדיקות יחידה ל:

- **`useTimer`** — ספירה לאחור/מעלה, השהיה/המשך ללא סטייה (drift), הוספת
  שניות, קריאה ל-`onComplete`.
- **`progression`** — חישוב השבוע הנוכחי לפי תאריך התחלה, והתאמת
  חזרות/זמן/עצימות בכל טווח שבועות.
- **`plan`** — סטטוס אימון לפי שבוע/משבצת, האימון הבא המוצע, רצף אימונים,
  אחוז השלמה כולל.

הרצה: `npm test`.

## נגישות ושימושיות

- כל הכפתורים בגדלים נוחים למגע (44px+), עם `aria-label` היכן שאין טקסט
  גלוי.
- סטטוס אימון מוצג עם אייקון + טקסט, לא רק צבע.
- טיימר במסך האימון קריא מרחק — טקסט גדול, ניגודיות גבוהה על רקע כהה.
- גודל טקסט ניתן להגדלה מהגדרות (רגיל/גדול/גדול מאוד), עם משתנה CSS גלובלי.
- `Wake Lock API` שומר את המסך דלוק בזמן אימון (עם נפילה שקטה במכשירים
  ללא תמיכה).

## הערות מימוש

- הראוטר משתמש ב-`HashRouter` (לא `BrowserRouter`) כדי שרענון דף / פתיחה
  ישירה מקישור יעבדו נכון גם באחסון סטטי (למשל GitHub Pages) בלי צורך
  בהגדרות rewrite בצד השרת — חשוב במיוחד ל-PWA שנטען Offline.
- כל הצלילים בזמן האימון (התחלה/אזהרת 5 שניות/סיום) מסונתזים ב-WebAudio
  (`useSound`) — אין קבצי אודיו חיצוניים, כדי לא להעמיס את חבילת ה-build.
